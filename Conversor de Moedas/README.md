# Conversor de Moedas

Este projeto é um **Conversor de Moedas** desenvolvido em Java. O objetivo é permitir que o usuário converta valores entre diferentes moedas através de uma interação simples e intuitiva via console.

## Funcionalidades

- O usuário pode escolher entre várias opções de conversão de moedas, incluindo:
  - USD para EUR
  - EUR para USD
  - BRL para USD
  - USD para BRL
  - BRL para EUR
  - EUR para BRL
- O programa utiliza uma API externa para obter as taxas de câmbio mais recentes, garantindo que as conversões sejam precisas.
- Após a escolha da conversão desejada, o usuário informa o valor que deseja converter e o programa retorna o valor convertido.

## Objetivo

O principal objetivo deste projeto é fornecer uma ferramenta prática para conversão de moedas, utilizando conceitos de programação, como requisições HTTP e manipulação de JSON. Além disso, é uma oportunidade para aplicar e consolidar os conhecimentos adquiridos em cursos de programação, além de explorar a integração com APIs.

## Como Usar

1. Clone este repositório ou faça o download dos arquivos.
2. Compile e execute a classe `ConversorMoedas`.
3. Siga as instruções exibidas no console para realizar a conversão de moedas desejada.

## Tecnologias Utilizadas

- Java
- API para conversão de moedas (Exchangerate API)
- Bibliotecas Gson para manipulação de JSON
